# Silhouette — downloads

Silhouette is a Windows desktop app for faceless YouTube creators: warm-up scheduling, engagement and channel operations on top of IXBrowser.

## Download

Get the latest `Silhouette-<version>-win64.zip` from the **Releases** page of this repository.

## Install (2 minutes)

1. Unzip the file anywhere, for example `C:\Silhouette`.
2. Run `Silhouette.exe`.
3. Open the **License** page and enter your license key.
4. Add your own LLM API keys (Gemini / OpenAI / Groq) and connect Slack from **Settings**.

Node.js is bundled — nothing else to install. IXBrowser must be installed and running on the same PC.

## Requirements

Windows 10/11 (64-bit), IXBrowser, internet access for license checks.
